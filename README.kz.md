# Career Quest

**Тіл:** [English (ENG)](README.md) | [Русский (RU)](README.ru.md) | **Қазақша (KZ)**

HackAlem AI хакатонының Halyk Bank бағытына арналған қызметкерлердің даму навигаторы. Қолданбада негіздемесі бар ұсыныстар, мансаптық даму жолдары, ерікті іс-шаралар, дағдыларды жаңарту, даму журналы, HR талдауы және қазылар алқасының тест деректерін жүктеу мүмкіндігі бар.

## Іске қосу

Node.js 22 немесе одан жаңа нұсқасы қажет. Тәуелділіктерді орнатудың немесе фронтендті құрастырудың қажеті жоқ.

```sh
npm start
```

Windows PowerShell ортасында скрипттерді орындауға тыйым салынса, `npm.cmd start` пәрменін пайдаланыңыз. **http://127.0.0.1:3000** мекенжайын ашыңыз.

| Жұмыс кеңістігі | Логин | Әдепкі құпиясөз |
| --- | --- | --- |
| E0028 қызметкері — берілген деректер жинағында Akmaral Ismailova | `employee` | `grow-together` |
| HR маманы | `hr` | `support-growth` |

`EMPLOYEE_ID` айнымалысы қызметкердің демонстрациялық есептік жазбасын басқа профильге байланыстыруға мүмкіндік береді. Есімдер жүктелген деректерден алынады. Серверді loopback мекенжайынан басқа желілік интерфейсте іске қосқанда жеке құпиясөздер орнату қажет.

## Берілген деректер жинағы

`career_quest_dataset.zip` мұрағаты **data/source/** қалтасына ашылып, деректер **data/state.json** файлына жүктелді. Бастапқы мұрағат өзгертілмеген. Қолданбаның алдыңғы күйінің сақтық көшірмесі **data/backups/** қалтасында. Бастапқы жазбалар, жұмыс күйі және сақтық көшірмелер Git жүйесіне қосылмайды.

- 8 рөл бойынша 200 қызметкер.
- Міндетті процестерді қоса алғанда 40 іс-шара.
- 60 дағды және рөл мен грейдтің 32 тіркесіміне арналған талаптар профилі.
- Қатысу тарихындағы 2 743 жазба.
- Деректердің кесінді күні: **2026-10-01**. Қолданба есептеулерде осы күнді ағымдағы күн ретінде пайдаланады.

Сақталған күйі жоқ алғашқы іске қосу кезінде сервер `data/source/` қалтасы бар болса, деректерді содан жүктейді. Әйтпесе бастапқы демонстрациялық деректер жинағын жасайды. `DATASET_MODE=demo` күй файлы болмаған кезде демонстрациялық деректерді жасауды тікелей таңдайды. Сақталған күй әрқашан басымдыққа ие.

Деректер жинағын толық ауыстыру үшін серверді тоқтатыңыз, бастапқы жинақтың төрт деректер файлын `data/source/` қалтасына ашыңыз да, мына пәрмендерді орындаңыз:

```sh
npm run import:dataset
npm start
```

Ашылған файлдары бар басқа қалтаны да көрсетуге болады: `npm run import:dataset -- /path/to/dataset`. Бұл пәрмен алдымен деректерді тексереді, содан кейін бар күйдің сақтық көшірмесін жасап, оны атомарлы түрде ауыстырады. Сервер жұмыс істеп тұрғанда бұл көшіру пәрменін іске қоспаңыз; серверді тоқтатпай жаңарту үшін HR импорт экранын пайдаланыңыз.

HR экраны бастапқы `employees.json`, `events.json`, `skills.json` және `activity_history.csv` файлдарын бірге, біріктірілген JSON файлын немесе жеке профильдер мен тарихты қабылдайды. JSON қаптамалары, метадеректер, рөл профильдері және меңгеру деңгейлерінің сипаттамалары сақталады. Тексеру деректерді өзгертпейді; импортты қолданған кезде ағымдағы күйдің нұсқасы тексеріледі. Профильдер, іс-шаралар және дағдылар ID бойынша біріктіріледі. Жүктелген тарих тек сол тарих файлында көрсетілген қызметкерлердің жазбаларын ауыстырады. Бос тарих файлы бар жазбаларды өзгертпейді.

HR экспорты — бастапқы өрістер мен соңғы бағалаудағы базалық деңгейлерді қамтитын, қолданбаның біріздендірілген күй көшірмесі. Оны дағды өсімін екі рет есептемей қайта импорттауға болады. Қазылар алқасының бастапқы форматтағы қосымша профильдері мен тарихы схеманы өзгертпей жүктеледі. Берілген каталогпен үйлесімді мысал: `fixtures/jury-profiles.json`.

## OpenAI және жергілікті ЖИ

Сервер OpenAI, жергілікті Ollama және көп факторлы ережелер режимін қолдайды. API кілттерін тек сервер оқиды; олар браузерге берілмейді және бастапқы кодқа қосылмайды.

Жаңа кілтті жергілікті түрде баптау үшін `.env.example` файлын `.env` файлына көшіріп, `OPENAI_API_KEY` мәнін толтырыңыз да, серверді қайта іске қосыңыз:

```dotenv
AI_PROVIDER=openai
OPENAI_API_KEY=your-new-key
OPENAI_MODEL=gpt-4.1-mini
```

`.env` файлын Git жүйесіне қоспаңыз және кілттерді чатқа жібермеңіз. Орта айнымалылары `.env` файлындағы мәндерден басым. Тек сервер процесінің ортасында берілген кілт сол процесс үшін уақытша қолданылады; процесс аяқталғаннан кейін оны қайта баптау қажет.

OpenAI режимі [Structured Outputs бар Responses API](https://developers.openai.com/api/docs/guides/structured-outputs) пайдаланады. Әдепкі модель — құрылымды жауапты қолдайтын [GPT-4.1 mini](https://developers.openai.com/api/docs/models/gpt-4.1-mini). Модельді `OPENAI_MODEL` арқылы өзгертуге болады. ЖИ тексерілген үміткерлер тізімінен 1–3 іс-шараны таңдайды. Қолданба қайтарылған ID мәндерін, олардың қайталанбауын және түсіндірменің ұзындығын қосымша тексереді. Модель мәтіні қолданба есептеген фактілерден бөлек көрсетіледі және қателерді қамтуы мүмкін.

**Деректерді жіберу:** OpenAI режимінде `api.openai.com` мекенжайына рөл, грейд, еңбек өтілі, мансаптық мақсат, жұмыс форматы, ағымдағы дағдылар, сәйкес іс-шаралар және қатысу тарихынан алынған деректер жіберіледі. Қызметкерлердің есімдері, қызметкер мен басшының ID мәндері және тарихтың бастапқы жазбалары жіберілмейді. Сұрауларда `store: false` көрсетіледі; бұл деректердің мүлде сақталмайтынына кепілдік бермейді. Бұл режимді хакатон ережелері осындай өңдеуге рұқсат еткен жағдайда ғана пайдаланыңыз. Жергілікті ережелер режиміне API кілті қажет емес.

Толық жергілікті өңдеу үшін орнатылған жергілікті моделі бар Ollama серверін іске қосып, мына мәндерді орнатыңыз:

```dotenv
AI_PROVIDER=ollama
OLLAMA_MODEL=your-installed-model
OLLAMA_URL=http://127.0.0.1:11434
```

Ollama мекенжайлары loopback аясымен шектеледі, қайта бағыттаулар қабылданбайды. Бұлт арқылы жұмыс істейтін Ollama моделінің орнына жергілікті модельді пайдаланыңыз. Тек ережелермен жұмыс істеу үшін `AI_PROVIDER=rules` орнатыңыз. Провайдер нақты көрсетілмесе, OpenAI кілті бар кезде OpenAI, әйтпесе Ollama моделі бар кезде Ollama таңдалады. Екеуі де болмаса, ережелер қолданылады.

Сұраудың күту шегі — сегіз секунд. Кілт немесе модель болмаса, қате туындаса, квота шектелсе, жауап толық болмаса немесе модель таңдауы тексеруден өтпесе, қолданба ережелерге ауысқанын анық көрсетеді. Сәтті ұсыныстар әр қызметкер мен деректер жинағының нұсқасы үшін бес минутқа кэштеледі; деректер өзгергенде кэш тазаланады. Модель жылдамдығын және ұсынысты 10 секунд ішінде беру талабын таңдалған модель мен орналастыру желісінде тексеру қажет.

## Деректерді өңдеу және ұсыныс беру ережелері

- **Соңғы бағалауды есепке алу.** Бастапқы `skills` мәндері `assessed_skills` өрісінде сақталады. Күні `last_review_date` мәнінен кейін және деректердің кесінді күнінен кеш емес аяқталған іс-шаралар әр іс-шараның өсімі мен шегін ескере отырып, хронологиялық ретпен қолданылады. Қайта импорттау дағдыларды базалық бағалаудан қайта есептеп, өсімнің екі рет есептелуін болдырмайды. Бағалау күні өткен іс-шаралар бағалауда ескерілген деп саналады. Дереккөзде нақты аяқталу уақыты емес, сабақ немесе тіркелу күні берілгендіктен, есептеуде қолжетімді `date` өрісі пайдаланылады. Уақтылы аяқталғаны белгісіз болса, қолданба оны ойдан қоспайды.
- **Мансаптық мақсаттар.** Нақты көрсетілген `career_goal.target_role/target_grade` мәндері басымдыққа ие. Мақсат болмаса, ағымдағы рөлдің келесі грейді қолданылады. Мақсаты жоқ Lead үшін келесі грейд ойдан жасалмайды. Көрсетілмеген дағдының деңгейі — 0. Рөлді ауыстыруды қоса алғанда, мақсатты талаптар `role_profiles.required_skills` және `critical_skills` арқылы анықталады.
- **Іс-шаралардың қолжетімділігі.** Міндетті іс-шаралар ұсыныстар мен ерікті даму каталогына кірмейді. Қызметкердің ағымдағы рөлі мен грейді іс-шара аудиториясына сәйкес келуі және барлық бастапқы талаптар орындалуы керек. Кесте бойынша өтетін іс-шараның алдағы сессиясы немесе бұрыннан бар қатысу тіркелімі болуы қажет. Рөлді ауыстыру мақсаты аудитория шектеулерін жоймайды.
- **Аяқтау.** Аяқталған іс-шараны қайта өтуге болмайды. Ерекшелік — жүйелі түрде өтетін `EV_036` көпшілік алдында сөйлеу клубы. Клубтың әр сессиясына жеке тіркелу қажет және бір сессия екі рет есептелмейді. Бастапқы деректердегі «орындалуда» күйіндегі іс-шаралар My plan бөлімінде көрсетіледі; олардан ерікті түрде шығу кейінгі қайта есептеулерде сақталады.
- **Ұсыныстардың реті.** Мақсатқа дейінгі алшақтықтың қысқаруы, оның көлемі, дағдының маңыздылығы, сәтті аяқтаулар мен қатысудан шығу, келмеу немесе бас тарту жағдайлары, нақты онлайн, офлайн не өз қарқынымен оқу форматындағы нәтижелер және уақыт шығыны ескеріледі. Қайталанбайтын аяқталған іс-шаралар алынып тасталады. Модель ең қолайлы қолжетімді нұсқаларды таңдап, таңдаудың себептерін түсіндіреді. Қашықтан жұмыс істейтін қызметкерге ұсынылған іс-шараның офлайн өтетіні ескертіледі.

Детерминирленген баға: `12 * gap_closure + 4 * gap_weighted_closure + 3 * format_completion_rate + min(relevant_completions, 3) - 5 * relevant_skips - 0.4 * hours`. Мұнда алшақтықтың қысқаруы, оның салмақталған қысқаруы, сол форматтағы аяқтау үлесі, қатысты аяқтаулар, қатыспау жағдайлары және сағат саны ескеріледі. Салмақталған қысқаруда маңызды дағдылардың салмағы екі есе артады. Жаңа формат үшін бастапқы бейтарап аяқтау үлесі — 0.5.

```text
new_level = max(current, min(5, activity.max_level, current + activity.gain))
readiness = round(100 * sum(min(current, target)) / sum(target))
```

Мақсатты талабы жоқ дағдылар дайындық көрсеткішінің бөлімін арттырмайды. Дайындық — қызметті жоғарылату туралы шешім емес, даму бағдары. Жеке дағдылардағы алшақтық пен маңызды талаптар көрініп тұрады. Қолданба интерфейсі ағылшын тілінде; бастапқы тіл қалаулары сақталады, бірақ интерфейстің орысша және қазақша нұсқалары әзірге іске асырылмаған. Осы файлдың басындағы тіл таңдауы құжаттаманың тілін ауыстырады.

Демонстрацияда қызметкер **аяқтауды өзі белгілейді**, сондықтан дағды деңгейлері, тіпті таңдалған болашақ сессия үшін де, бірден жаңарады. Бұл нақты қатысудың дәлелі емес. Жұмыс жүйесінде аяқталуды оқу платформасы арқылы тексеру қажет. Хакатон бағалауын қайталауға мүмкіндік беру үшін кесінді күні бекітілген.

## HR, құпиялылық және сақтау

HR дағдылардағы жалпы алшақтықты және қызметкерлердің әліпби ретімен берілген жабық профильдерін көреді. Қызметкерлердің ашық рейтингі жоқ. Қолдау сигналдары кесінді күніне дейінгі 90 күнде қайталанған келмеу немесе бас тарту жағдайларын не соңғы уақытта аяқталған іс-шараның болмауын білдіреді. Олар қызметкер тиімділігінің бағасы немесе жұмыстан кету болжамы емес. Журналда «орындалуда», «тоқтатылған» және «мерзімі өткен» күйлерін қоса алғанда барлық күйлер сақталады.

Қызметкер мен HR құқықтарының бөлінуі сервер маршруттарында тексеріледі. Қызметкер басқа адамның профилін сұрай алмайды; импорт, экспорт және топтық талдау тек HR үшін қолжетімді. Cookies файлдарында HttpOnly және SameSite=Strict атрибуттары бар; сессиялар сегіз сағат әрекет етеді. Басқа көзден келген деректерді өзгерту сұраулары қабылданбайды, кіру әрекеттерінің саны шектеледі. Сервер қайта іске қосылғанда сессиялар аяқталады. Күй бір сервер процесінде JSON файлын атомарлы ауыстыру арқылы сақталады.

| Айнымалы | Әдепкі мәні |
| --- | --- |
| `HOST`, `PORT` | `127.0.0.1`, `3000` |
| `STATE_FILE` | `data/state.json` |
| `DATASET_DIR` | `data/source` |
| `EMPLOYEE_ID` | `E0028` |
| `EMPLOYEE_PASSWORD`, `HR_PASSWORD` | Жоғарыдағы кестеде берілген демонстрациялық құпиясөздер |
| `COOKIE_SECURE` | HTTPS арқылы жұмыс істегенде `true` орнатыңыз |
| `AI_PROVIDER` | Жоғарыда сипатталған автоматты таңдау |
| `OPENAI_API_KEY` | Берілмеген |
| `OPENAI_MODEL` | `gpt-4.1-mini` |
| `OLLAMA_MODEL` | Берілмеген |
| `OLLAMA_URL` | `http://127.0.0.1:11434` |

Бұл — екі демонстрациялық есептік жазбасы бар хакатон прототипі. Өндірістік қолданыс үшін SSO, сенімді дерекқор, аудит журналы, сақталған деректерді шифрлау, HTTPS және оқу платформасы арқылы аяқталуды растау қажет. Нақты жеке деректерді жүктемеңіз.

## Тексеру

```sh
npm test
npm run check
```

Тесттер қолжетімділік құқықтарын, деректерді сақтауды, ұсыныстарды реттеудің күрделі жағдайларын, бастапқы жинақтың JSON қаптамаларын, рөл мен маңызды дағдылар талаптарын, рөл ауыстыру мақсаттарын, бастапқы талаптарды, кестелі, міндетті және қайталанатын іс-шараларды, бағалаудан кейінгі дағды өсімін, импорттың қайталанғанда нәтижені өзгертпеуін, CSV өңдеуді, OpenAI сұраулары мен жауаптарын тексеруді және жергілікті модель қолжетімсіз болғандағы резервтік режимді қамтиды. Толық берілген деректер жинағы `data/source/` бар кезде тексеріледі; тәуелсіз тест мысалдары оның схемасын бұл қалтасыз да тексереді. Автоматты ЖИ тесттері еліктелген жауаптарды пайдаланады және API кредиттерін жұмсамайды.

| Жол | Мақсаты |
| --- | --- |
| `server.js` | API, аутентификация, қолжетімділік құқықтары, сақтау, кэштеу |
| `lib/domain.js` | Іс-шараларға қолжетімділік, бағалау, даму, HR жиынтықтары, тексеру |
| `lib/dataset.js`, `lib/dataset-loader.js` | Бастапқы жинақ адаптері және бағалаудан кейінгі дағдыларды қайта есептеу |
| `lib/ai.js` | OpenAI / Ollama арқылы таңдау және тексерілетін резервтік режим |
| `scripts/import-dataset.js` | Сервер тоқтаған кезде сақтық көшірме жасап, деректер жинағын ауыстыру |
